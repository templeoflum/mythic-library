What this model assumes

This is a new illustrative toy built for this study, not an imported corpus artifact. The original is cos(2π × 3t + 0.35). The other curve is an analytic, lowest-frequency representative with the same uniform samples, over a 2-second display window. It is not a reconstruction computed from only these visible dots.

Above 6 samples/s, a strictly baseband-limited model recovers this 3 Hz sinusoid. At exactly 6, phase information is ambiguous. At 2, the lower-frequency representative is also on a Nyquist boundary. This persistent sinusoid is not a finite-energy signal; the full record distinguishes its assumptions. Noise, filtering, finite-window effects and actual image rendering are not simulated.
